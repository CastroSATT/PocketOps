Mac/
====

What belongs here
-----------------
macOS tools you may need on a stranger’s Mac without installing from the App Store.

Typical contents
----------------
  - Remote support: AnyDesk / RustDesk / TeamViewer .dmg (or .zip)
  - Browsers: Firefox or Chrome offline .dmg
  - Network: WireGuard / OpenVPN Connect installers
  - Disk / USB: balenaEtcher, Apple Configurator (if licensed), Disk Utility helpers
  - Editors: VS Code / Sublime portable-style zips if you use them
  - Scripts: shell helpers, brew bundle lists, setup notes

Tips
----
  Prefer .dmg / .pkg / notarized apps. Gatekeeper may still warn on unknown Macs.
  Keep installers small; the microSD is shared with the PC kit.
