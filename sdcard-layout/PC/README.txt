PC/
===

Windows field kit. Prefer portable builds (no Admin install) when you can.

Subfolders
----------
  Remote/       Remote desktop / support clients
  Network/      SSH, SFTP, VPN, Wi-Fi helpers
  Diagnostics/  Hardware / driver / SMART info
  Utilities/    Zip, editors, general tools
  Browsers/     Portable or offline browser installers

See each subfolder README.txt for suggested apps.
