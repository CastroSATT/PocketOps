PC/Browsers/
============

A clean browser when the machine’s own browser is broken, hijacked, or missing.

Typical contents
----------------
  - Firefox Portable (or offline Firefox installer)
  - Ungoogled Chromium / LibreWolf portable (optional)
  - Offline Chrome/Edge enterprise installer (optional, large)

Tips
----
  Portable Firefox is usually enough to download real fix tools over HTTPS.
