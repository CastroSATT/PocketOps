PC/Network/
===========

Talk to other machines and move files.

Typical contents
----------------
  - PuTTY suite (putty, pscp, psftp, plink, pageant)
  - WinSCP (portable)
  - Wireshark portable (optional, larger)
  - iperf / netcat builds (optional)
  - WireGuard / OpenVPN client installers
  - Wi-Fi profile export notes or small helper scripts

Tips
----
  Portable PuTTY + WinSCP covers most “need a shell / need a file” jobs.
