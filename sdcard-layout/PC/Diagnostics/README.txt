PC/Diagnostics/
===============

See what hardware and drivers a Windows box actually has.

Typical contents
----------------
  - CrystalDiskInfo (disk health / SMART)
  - HWiNFO (portable)
  - DevManView / USBDeview (NirSoft)
  - Speccy / Core Temp (optional)
  - Display Driver Uninstaller (DDU) — use with care
  - CPU-Z / GPU-Z portable (optional)

Tips
----
  Start with CrystalDiskInfo + HWiNFO for “is this dying?” checks.
