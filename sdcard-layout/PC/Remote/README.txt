PC/Remote/
==========

Remote access and “help me fix this PC” clients.

Typical contents
----------------
  - AnyDesk (portable .exe)
  - RustDesk (portable / offline installer)
  - TeamViewer QuickSupport
  - Chrome Remote Desktop host installer (.msi)
  - Splashtop SOS / similar (optional)

Tips
----
  QuickSupport-style builds need less install friction on locked-down machines.
  Keep versions updated; old clients often fail to connect.
