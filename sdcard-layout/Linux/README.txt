Linux/
======

What belongs here
-----------------
Tools for Linux desktops and recovery shells.

Typical contents
----------------
  - AppImages: firmware flasher, disk tools, browsers
  - Static binaries: curl, jq, nmap (where licenses allow)
  - .deb / .rpm offline packages you trust for common distros
  - Shell scripts: network dump, package inventory, mount helpers
  - Remote: RustDesk / AnyDesk Linux builds
  - Live-USB notes (Ventoy paths, checksums)

Tips
----
  AppImages travel well across distros. Prefer x86_64 unless you know the target.
